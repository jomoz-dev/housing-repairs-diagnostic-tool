# Housing Repairs Diagnostic Tool

## Project Overview

The Housing Repairs Diagnostic Tool is a web\-based application developed using Python, Flask and SQLite.

The purpose of the application is to support housing organisations in assessing repair requests, assigning priorities, recommending trades, and providing management reporting.

The system applies business rules to categorise repairs and determine appropriate response times.

## Key Features

- Water Leak Assessment
- Electrical Assessment
- Heating Assessment
- Damp & Mould Assessment
- Roofing Assessment
- Doors & Windows Assessment
- Automatic Priority Assignment
- Unique Reference Number Generation
- Assessment History
- Search by Reference Number
- Dashboard Analytics
- CSV Export Functionality
- Assessment Filtering

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git
- GitHub

## Business Value

The application demonstrates how repair requests can be standardised through predefined business rules, improving consistency, reporting and operational efficiency.

The system provides management information through dashboards, search functionality and exported reports.
