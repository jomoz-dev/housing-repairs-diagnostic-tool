# User Guide

## Creating an Assessment

1. Open the application.
2. Select a repair category.
3. Complete the assessment questions.
4. Submit the assessment.
5. Review the results.

## Viewing Assessment History

1. Select History.
2. Review previously submitted assessments.

## Filtering Assessments

1. Open Assessment History.
2. Select a Priority.
3. Select a Repair Type (if required).
4. Click Filter.

## Searching for an Assessment

1. Open Search.
2. Enter the Reference Number.
3. Click Search.

## Exporting Data

1. Select Export CSV.
2. Open the downloaded file in Excel or Numbers.
